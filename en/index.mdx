## Use this documentation

Guides explain complete workflows. The API reference provides fields, responses and interactive request controls. Start with a minimal call, add parameters for your task, then use the HTTP status and error body with [Error troubleshooting](/en/help/errors) if needed.

Chinese and English follow the same topics. Use the language selector at the top of the page; endpoint paths and parameter names remain identical across languages.

## Service addresses

| Service | Address | Purpose |
| --- | --- | --- |
| Website | [maxapi.ai](https://maxapi.ai) | Product information |
| Console | [platform.maxapi.ai](https://platform.maxapi.ai) | Account and API key management |
| API | `https://api.maxapi.ai` | Direct HTTP requests |
| Compatible SDK base URL | `https://api.maxapi.ai/v1` | Configure OpenAI-compatible clients |

## Continue building

Use the [Python guide](/en/guides/python) or [Node.js guide](/en/guides/nodejs) to add MaxAPI to an application. Then add [streaming](/en/guides/streaming), [image understanding](/en/guides/vision) or [tool calling](/en/guides/tools).

For image, video and music workflows, start with the [multimedia overview](/en/media/index). Model access and protocol support depend on your account configuration; the extended catalog is a structural reference, not a guarantee that every route is enabled.
