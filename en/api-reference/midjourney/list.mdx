List tasks returns Midjourney records visible to the current credentials and channel. The response is directly a task array. It is not a cross-account platform listing or permanent history storage.

## Read the list

```bash Save visible tasks
curl --fail-with-body \
  "${MAXAPI_MJ_BASE_URL:-https://api.maxapi.ai/mj}/task/list" \
  -H "Authorization: Bearer $MAXAPI_API_KEY" \
  --output mj-list.json
```

```bash Inspect task summaries
jq -r '.[] | [.id, .action, .status, (.state // "")] | @tsv' mj-list.json
```

Use `state` to help associate application records, but identify each task by `id`. Save task IDs, modes, and generated outputs in your application for longer-term use.
