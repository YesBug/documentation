## 按你要完成的任务阅读

| 你的目标 | 从这里开始 | 完成后应得到 |
| --- | --- | --- |
| 第一次调用 API | [快速开始](/zh/quickstart) | 本机可运行的 Python、Node.js 或 cURL 请求 |
| 开发聊天应用 | [文本生成](/zh/guides/text-generation) → [流式响应](/zh/guides/streaming) | 保留上下文、逐段展示回复，并识别中断 |
| 让模型读取图片或调用业务函数 | [图像理解](/zh/guides/vision)、[工具调用](/zh/guides/tools) | 正确的多模态输入与完整工具调用闭环 |
| 做文档检索 | [Embeddings](/zh/api-reference/embeddings) | 文本向量、输入映射和相似度计算示例 |
| 生成或编辑图片 | [图像生成](/zh/api-reference/images)、[图像编辑](/zh/api-reference/images-edits) | 保存 URL 或 Base64 返回的图片 |
| 处理语音 | [语音生成](/zh/api-reference/audio-speech)、[音频转录](/zh/api-reference/audio-transcriptions) | 音频文件或转录文本 |
| Midjourney 绘图与局部重绘 | [快速开始](/zh/media/midjourney) → [后续动作](/zh/media/midjourney/actions) | 使用正确的任务 ID、按钮与蒙版完成交互 |
| 生成视频 | [统一视频指南](/zh/media/videos) → [接口调试](/zh/api-reference/videos/index) | 创建视频任务、查询状态并下载结果 |
| 生成音乐与续写 | [Suno 指南](/zh/media/music) → [协议与接口](/zh/api-reference/suno/index) | 区分任务 ID 与歌曲 ID，查询和保存音频 |
| 迁移和上线应用 | [迁移指南](/zh/guides/migration)、[超时与重试](/zh/guides/production) | 接入核对、并发管理和故障恢复策略 |

## 这份文档怎么用

开发指南解释完整流程；API 参考展示字段、响应和在线调试控件。先跑通一个最小请求，再按任务加入参数，遇到问题时带着 HTTP 状态与错误正文查看 [错误排查](/zh/help/errors)。

中文与英文按相同主题组织，可使用页面顶部的语言切换入口。所有代码里的接口路径和参数名保持一致。

## 服务地址

| 入口 | 地址 | 用途 |
| --- | --- | --- |
| 官网 | [maxapi.ai](https://maxapi.ai) | 了解 MaxAPI |
| 控制台 | [platform.maxapi.ai](https://platform.maxapi.ai) | 管理账户、获取密钥并查看模型权限 |
| API 服务 | `https://api.maxapi.ai` | 发送原始 HTTP 请求 |
| SDK Base URL | `https://api.maxapi.ai/v1` | 配置 OpenAI 兼容客户端 |

<Note>
可用模型、价格、配额和协议支持范围，以当前控制台与实际接口结果为准。扩展接口目录用于核对共用系统的结构，不代表所有功能均已对账户开通。
</Note>
