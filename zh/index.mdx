## 服务地址

| 入口 | 地址 | 用途 |
| --- | --- | --- |
| 官网 | [maxapi.ai](https://maxapi.ai) | 了解 MaxAPI |
| 控制台 | [platform.maxapi.ai](https://platform.maxapi.ai) | 管理账户、获取密钥并查看模型权限 |
| API 服务 | `https://api.maxapi.ai` | 发送原始 HTTP 请求 |
| SDK Base URL | `https://api.maxapi.ai/v1` | 配置 OpenAI 兼容客户端 |

<Note>
可用模型、价格、配额和协议支持范围，以当前控制台与实际接口结果为准。扩展接口目录用于核对共用系统的结构，不代表所有功能均已对账户开通。
</Note>
