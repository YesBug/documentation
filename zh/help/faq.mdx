这里汇总 MaxAPI 接入时常见的配置、模型、流式响应和任务查询问题。先核对接口地址与模型 ID，再结合当前账户的权限和实际响应定位原因。

## 官网、控制台和接口地址有什么区别？

| 入口 | 地址 | 用途 |
| --- | --- | --- |
| 官网 | [maxapi.ai](https://maxapi.ai) | 了解 MaxAPI |
| 控制台 | [platform.maxapi.ai](https://platform.maxapi.ai) | 管理账户、获取密钥并查看账户相关信息 |
| API | `https://api.maxapi.ai` | 应用程序发起接口请求 |

使用 OpenAI 兼容 SDK 时，将 Base URL 配置为 `https://api.maxapi.ai/v1`。

## 可以沿用 OpenAI SDK 吗？

可以使用 OpenAI SDK 调用本文介绍的 Chat Completions 兼容接口。请同时设置 MaxAPI API Key、MaxAPI Base URL 和可用模型 ID。

不同接口及模型的支持情况可能不同，不应将 Chat Completions 兼容理解为支持 SDK 的全部接口。完整示例见 [Python SDK](/zh/guides/python) 和 [Node.js SDK](/zh/guides/nodejs)。

## 应该填写哪个模型名称？

填写 [模型列表接口](/zh/api-reference/models) 返回的准确模型 `id`，并确认该模型适合当前调用方式。不要直接填写官网展示名称，也不要假定其他平台的同名模型 ID 在 MaxAPI 上可用。

## 为什么示例使用 MAXAPI_MODEL？

环境变量让示例适用于不同账户和模型，也便于后续调整配置。执行示例前，请将它替换为当前可用的实际模型 ID。

## 为什么设置了 .env 仍然找不到 API Key？

`.env` 文件本身不会自动改变所有程序的运行环境。需要由框架、运行时或环境变量加载工具读取它，也可以在启动程序前直接设置环境变量。检查配置时不要把真实密钥打印到日志。

## 可以从浏览器直接调用 API 吗？

推荐让浏览器调用你自己的后端，由后端管理密钥并转发请求。写入前端代码或公开环境变量的 API Key 会暴露给访问者。参见 [身份验证](/zh/authentication)。

## 如何继续上一轮对话？

在下一次 Chat Completions 请求中，通过 `messages` 一并传入需要保留的历史消息。不要依赖客户端对象自动保存上下文。随着历史增长，应根据模型上下文限制进行裁剪或摘要。

## 为什么流式响应没有逐字显示？

确认请求启用了 `stream: true`，客户端按增量读取数据，且服务端和代理没有缓冲整个响应。模型可能以多个字符组成的数据块返回内容，不保证每个字符对应一个事件。参见 [流式响应](/zh/guides/streaming)。

## 在哪里查看价格、余额和用量？

请在 [模型概览](https://platform.maxapi.ai/modelmak) 查看模型信息，登录后在 [价格页面](https://platform.maxapi.ai/account/pricing) 核对当前价格，并在控制台查看自己的余额与用量记录。文档中的示例不代表价格、配额、服务承诺或实时可用模型范围。

## 遇到问题时应该提供哪些信息？

保留发生时间与时区、模型 ID、接口路径、HTTP 状态码以及已脱敏的错误内容。通过控制台提供的支持入口反馈，并在提交前移除密钥和敏感数据。完整检查步骤见 [错误排查](/zh/help/errors)。

## 同一个模型应该使用哪一种 API 格式？

根据应用需要选择一种已开通的格式：常规聊天使用 OpenAI 兼容接口；视频可采用统一任务接口，也可使用厂商原生兼容格式。Base URL、请求体和任务查询方式必须与所选格式配套，见 [选择接口格式](/zh/guides/protocols)。

## 为什么生成音乐或视频后没有立即获得文件？

这些通常是异步任务。提交时只返回任务标识，应用需要保存 ID 并轮询查询，或接收该接口支持的回调。不同接口的 ID 和终态字段不同，见 [异步任务](/zh/guides/async-tasks)。

## 目录中列出的接口都能直接调用吗？

不一定。[扩展接口目录](/zh/api-reference/catalog) 是共用 API 系统的结构索引。是否可用取决于账号的模型权限与通道配置，标为“需核对”或“示例路径”的定义还需先确认参数及路径。目录不表示所有功能已完成在线验证。

## 模型列表成功，为什么聊天或图片生成仍然失败？

模型列表只证明当前密钥能执行这次查询。聊天、绘图、语音和嵌入需要各自的模型能力。先核对模型对应的端点，再用最小请求测试，最后逐项增加参数。不要把“模型 ID 存在”当成“支持所有接口”。

## 在线调试成功，为什么复制到代码里就失败？

对比最终 URL、密钥来源、模型 ID 和请求体。特别检查 SDK Base URL 是否重复 `/v1`、程序是否加载环境变量，以及上传文件是否存在于服务端环境。调试面板经过文档代理，你的服务器还有自己的网络环境。见 [在线调试](/zh/playground)。

## 返回 HTTP 200 就代表生成成功吗？

还要检查结果。聊天应检查 `choices` 和结束原因；工具调用需要应用继续执行；异步视频或音乐只返回任务 ID 时，还要查询终态。音频和字幕还需使用正确的响应读取方式。见 [API 总览](/zh/api-reference/index)。

## `max_tokens` 和 `max_completion_tokens` 应该用哪个？

选择模型明确支持的参数，不要同时发送两者。它们不能在所有模型上互相替换，部分模型的生成预算可能包含推理 token。先验证不带长度参数的最小请求，再增加该模型支持的输出控制字段。

## `usage` 能直接换算成扣费金额吗？

`usage` 是接口返回的用量信息，不是统一计费公式。不同模型可能返回不同字段，图像、音频或异步任务也不能一律按聊天 token 计费。价格、金额和账户记录以控制台当前信息为准。

## 请求超时后，可以立即重发吗？

超时表示客户端在等待期限内没有拿到完整结果，不能证明服务端没有处理。对生成操作，先检查已返回的任务 ID、可查询状态或控制台记录。确认适合重试后再有限次重试，避免生成重复结果。

## 图片接口只返回 Base64，怎么拿到文件？

从 `data[].b64_json` 取出内容并解码成字节，再按实际格式保存。不能把 Base64 字符串直接当作 PNG 文件。完整 URL/Base64 批量保存示例见 [图像生成](/zh/api-reference/images)。

## 音频请求为什么报 JSON 解析错误？

语音合成返回音频字节；转录或翻译在字幕模式下返回文本；只有对应 JSON 输出才应调用 JSON 解析器。先检查 HTTP 状态与 Content-Type，再选择读取方式，见 [文本转语音](/zh/api-reference/audio-speech) 和 [音频转录](/zh/api-reference/audio-transcriptions)。

## 音频翻译能直接指定日文或中文吗？

本页记录的 `/v1/audio/translations` 输出英文。其他目标语言先转录为原文，再使用聊天模型翻译文字。需要语音时，再把翻译文字交给语音合成。可运行示例见 [音频翻译](/zh/api-reference/audio-translations)。

## 文档示例中的超时、批次和尺寸是平台限制吗？

不是。标注为示例的客户端参数用于演示接入方式。实际模型能力、输入大小、速率与其他限制需要根据所用模型和账户配置确认，不应从代码样例反推出平台统一限制。
