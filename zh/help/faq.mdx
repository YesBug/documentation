这里汇总 MaxAPI 接入时常见的配置、模型、流式响应和任务查询问题。先核对接口地址与模型 ID，再结合当前账户的权限和实际响应定位原因。

## 官网、控制台和接口地址有什么区别？

| 入口 | 地址 | 用途 |
| --- | --- | --- |
| 官网 | [maxapi.ai](https://maxapi.ai) | 了解 MaxAPI |
| 控制台 | [platform.maxapi.ai](https://platform.maxapi.ai) | 管理账户、获取密钥并查看账户相关信息 |
| API | `https://api.maxapi.ai` | 应用程序发起接口请求 |

使用 OpenAI 兼容 SDK 时，将 Base URL 配置为 `https://api.maxapi.ai/v1`。

## 可以沿用 OpenAI SDK 吗？

可以使用 OpenAI SDK 调用本文介绍的 Chat Completions 兼容接口。请同时设置 MaxAPI API Key、MaxAPI Base URL 和可用模型 ID。

不同接口及模型的支持情况可能不同，不应将 Chat Completions 兼容理解为支持 SDK 的全部接口。完整示例见 [Python SDK](/zh/guides/python) 和 [Node.js SDK](/zh/guides/nodejs)。

## 应该填写哪个模型名称？

填写 [模型列表接口](/zh/api-reference/models) 返回的准确模型 `id`，并确认该模型适合当前调用方式。不要直接填写官网展示名称，也不要假定其他平台的同名模型 ID 在 MaxAPI 上可用。

## 为什么示例使用 MAXAPI_MODEL？

环境变量让示例适用于不同账户和模型，也便于后续调整配置。执行示例前，请将它替换为当前可用的实际模型 ID。

## 为什么设置了 .env 仍然找不到 API Key？

`.env` 文件本身不会自动改变所有程序的运行环境。需要由框架、运行时或环境变量加载工具读取它，也可以在启动程序前直接设置环境变量。检查配置时不要把真实密钥打印到日志。

## 可以从浏览器直接调用 API 吗？

推荐让浏览器调用你自己的后端，由后端管理密钥并转发请求。写入前端代码或公开环境变量的 API Key 会暴露给访问者。参见 [身份验证](/zh/authentication)。

## 如何继续上一轮对话？

在下一次 Chat Completions 请求中，通过 `messages` 一并传入需要保留的历史消息。不要依赖客户端对象自动保存上下文。随着历史增长，应根据模型上下文限制进行裁剪或摘要。

## 为什么流式响应没有逐字显示？

确认请求启用了 `stream: true`，客户端按增量读取数据，且服务端和代理没有缓冲整个响应。模型可能以多个字符组成的数据块返回内容，不保证每个字符对应一个事件。参见 [流式响应](/zh/guides/streaming)。

## 在哪里查看价格、余额和用量？

请登录 [控制台](https://platform.maxapi.ai) 查看账户提供的信息与当前模型说明。文档中的示例不代表价格、配额、服务承诺或实时可用模型范围。

## 遇到问题时应该提供哪些信息？

保留发生时间与时区、模型 ID、接口路径、HTTP 状态码以及已脱敏的错误内容。通过控制台提供的支持入口反馈，并在提交前移除密钥和敏感数据。完整检查步骤见 [错误排查](/zh/help/errors)。

## 同一个模型应该使用哪一种 API 格式？

根据应用需要选择一种已开通的格式：常规聊天使用 OpenAI 兼容接口；视频可采用统一任务接口，也可使用厂商原生兼容格式。Base URL、请求体和任务查询方式必须与所选格式配套，见 [选择接口格式](/zh/guides/protocols)。

## 为什么生成音乐或视频后没有立即获得文件？

这些通常是异步任务。提交时只返回任务标识，应用需要保存 ID 并轮询查询，或接收该接口支持的回调。不同接口的 ID 和终态字段不同，见 [异步任务](/zh/guides/async-tasks)。

## 目录中列出的接口都能直接调用吗？

不一定。[扩展接口目录](/zh/api-reference/catalog) 是共用 API 系统的结构索引。是否可用取决于账号的模型权限与通道配置，标为“需核对”或“示例路径”的定义还需先确认参数及路径。目录不表示所有功能已完成在线验证。
