扩展接口目录保留共用 API 系统导出文件中的 173 条结构定义，方便按功能、提供方和路径核对。**这些条目并不代表 MaxAPI 已全部开通，也不代表每条定义都已完成在线验证。**

常用接口的参数与在线调试见 [API 总览](/zh/api-reference/index)；视频、音乐与图像任务的接入流程见 [多媒体接入](/zh/media/index)。

## 阅读目录

| 标记 | 含义 |
| --- | --- |
| 协议参考 | 可用于定位接口及核对字段，仍需确认账号通道和模型权限 |
| 需核对 | 字段缺失、路径模板冲突或协议说明不一致，接入前应进一步核实 |
| 示例路径 | 含示例标识或占位内容，不能作为真实任务地址直接调用 |

字段表保留来源中的名称、类型与必填标记，尚未定义的部分不在此补造。目录未保留原始认证值、请求样例、第三方媒体地址或价格；固定任务与文件标识已替换为示例占位符。认证方式见 [身份验证](/zh/authentication)。

目录中的同路径分支与模板差异按来源保留，因此 173 条记录不等于 173 个已经验证的独立可用操作。

## 使用方式

OpenAI SDK 的 Base URL 为 `https://api.maxapi.ai/v1`；直接调用扩展协议时，使用 API 根地址 `https://api.maxapi.ai` 加上已确认的接口路径。不要自动向原生路径再添加 `/v1`。

若出现多个仅参数名称不同的路径，应先核对真实路由和返回体。异步请求还需要确认对应查询方法，完整流程见 [异步任务与回调](/zh/guides/async-tasks)。
