MaxAPI 的 API 服务地址为 `https://api.maxapi.ai`。使用 OpenAI 兼容 SDK 时，将 Base URL 设置为 `https://api.maxapi.ai/v1`。

以下文档按功能与协议组织。可用模型、通道和扩展能力以账号配置为准；接口目录表示共用系统的协议参考，不代表所有扩展接口都已对当前账号开通。

常用接口页面提供原生 **Try it** 调试面板，可填写 API Key、编辑 JSON 或上传文件。使用方式见 [在线调试](/zh/playground)；生成请求可能产生实际用量。

## 文本与向量

| 任务 | 方法与路径 | 文档 |
| --- | --- | --- |
| 多轮对话、流式输出 | `POST /v1/chat/completions` | [创建对话](/zh/api-reference/chat-completions) |
| 旧式 prompt 文本补全 | `POST /v1/completions` | [文本补全](/zh/api-reference/completions) |

图片理解通过支持视觉输入的聊天模型完成，见 [图像理解](/zh/guides/vision)。让模型提出函数调用并由应用执行，见 [工具调用](/zh/guides/tools)。

## 视频与音乐任务

| 任务 | 入口 | 阅读顺序 |
| --- | --- | --- |
| 统一视频生成 | `/v2/videos/generations` | [提交与查询](/zh/media/videos) → [异步任务](/zh/guides/async-tasks) |
| 厂商原生视频格式 | Wan、Veo、Seedance、Vidu、Hailuo、Luma、Kling、Runway | [厂商接口差异](/zh/media/video-providers) |
| Midjourney 图像与动作 | `/mj/submit/...`、`/mj/task/...` | [Midjourney](/zh/media/midjourney) |
| Suno 音乐 | `/suno/v2/...` 或 `/suno/submit/...` | [音乐生成](/zh/media/music) |

先选择一种协议完成整条流程，再增加其他格式。任务标识、回调字段和状态枚举不能在不同协议间直接替换。

## 扩展接口目录

[打开扩展接口目录](/zh/api-reference/catalog)，按功能分组查看共用系统导出的接口路径、方法与字段。

目录中标为「需核对」或「示例路径」的接口包含不完整或有歧义的定义。接入时，请先确认实际路径、模型权限和请求结构。

## 通用约定

- 通过 HTTPS 调用，按 [身份验证](/zh/authentication) 传入 `Authorization: Bearer ...`。
- JSON 与文件上传使用不同的 Content-Type，见 [选择接口格式](/zh/guides/protocols)。
- 检查 HTTP 状态后再按协议解析内容；生成失败与网络错误分别处理。
- 保留可追踪的请求或任务标识，日志中隐藏密钥和敏感输入。
- 模型价格、时长、分辨率和用量限制以控制台及所用模型说明为准。
