音频翻译接口将上传的语音转换为英文文本。它接收实际音频文件，需使用支持该端点的模型；若希望保留原语言，请使用 [音频转录](/zh/api-reference/audio-transcriptions)。

## 翻译为英文

将 `MAXAPI_AUDIO_MODEL` 切换为支持翻译端点的模型。该端点不是任意目标语言转换器，不要通过 `language` 指定输出语言。

```bash cURL：音频翻译
curl --fail-with-body https://api.maxapi.ai/v1/audio/translations \
  -H "Authorization: Bearer $MAXAPI_API_KEY" \
  -F "model=$MAXAPI_AUDIO_MODEL" \
  -F "file=@meeting.mp3" \
  -F "response_format=json"
```

JSON 格式的英文结果同样位于 `text`。如果需要其他目标语言，可以先转录，再通过 [对话接口](/zh/api-reference/chat-completions) 翻译得到的文字。

## 保存英文翻译

在上面的 cURL 命令末尾增加 `--output translation.json`。确认请求成功后，运行以下脚本将 `text` 保存为 UTF-8 文本。

```python 保存翻译结果
import json
from pathlib import Path

result = json.loads(Path("translation.json").read_text(encoding="utf-8"))
text = result.get("text")
if not isinstance(text, str):
    raise ValueError("没有英文翻译文字，请检查原始响应")
Path("translation-en.txt").write_text(text, encoding="utf-8")
print(text)
```

结构示意如下；正文仅用于解释返回格式，不是实际音频的识别结果。

```json JSON 结果示意
{"text": "The meeting will begin at ten tomorrow morning."}
```

## 翻译成其他语言

需要日文、中文或其他目标语言时，采用两步流程：先用 [音频转录](/zh/api-reference/audio-transcriptions) 获取原语言文本，保存为 `transcript.txt`；再让支持目标语言的聊天模型翻译。这样也便于保留原文和检查翻译质量。

下面的命令依赖 `jq`。`--rawfile` 读取整段文字并安全地构造 JSON，避免换行或引号破坏请求体。

```bash 将转录文本翻译成日文
jq -n --arg model "$MAXAPI_MODEL" --rawfile transcript transcript.txt '{
  model: $model,
  messages: [{
    role: "user",
    content: ("请将以下录音转录内容翻译成日文，保留专有名称和段落，只返回翻译：\n\n" + $transcript)
  }]
}' | curl --fail-with-body https://api.maxapi.ai/v1/chat/completions \
  -H "Authorization: Bearer $MAXAPI_API_KEY" \
  -H "Content-Type: application/json" \
  --data-binary @-
```

第二步结果位于 `choices[].message.content`，不是音频接口的 `text`。两步调用分别产生各自的请求和用量；长转录文本还需符合聊天模型的上下文限制。

| 目标 | 选择的流程 |
| --- | --- |
| 保留录音原语言 | 音频转录 |
| 直接输出英文 | 本页音频翻译端点 |
| 输出任意其他目标语言 | 先转录，再使用聊天模型翻译文字 |
| 生成翻译后的朗读音频 | 获得目标文字后，再调用 [文本转语音](/zh/api-reference/audio-speech) |

## 文件与返回格式

使用 `multipart/form-data` 上传实际音频，不要将本地文件名或网页 URL 当作文件正文。文件格式、大小与时长限制以所用模型要求为准。

需要英文术语提示时，按模型支持情况传入 `prompt`。模型支持 `srt` 或 `vtt` 时，返回内容应作为字幕文本保存；选择 JSON 输出时，从 `text` 读取翻译结果。

上传失败或字幕格式不受支持时，先使用一段有效短音频和最小参数验证，再恢复其他设置。更多排查步骤见 [错误排查](/zh/help/errors)。
